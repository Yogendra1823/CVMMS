# CitizenVoiceMMS 🎤

**CitizenVoiceMMS** is a modern, web-based Municipal Management System that enables citizens to report issues, track complaints, and provide feedback to municipal authorities. It's built to amplify public concerns and promote civic engagement through an intuitive and accessible interface.

🔗 **Live Site:** [citizenvoicemms.netlify.app](https://citizenvoicemms.netlify.app/)

---

## ✨ Features

- 📝 Report municipal issues and complaints
- 🔍 Track complaint status in real-time
- 💬 Provide feedback on municipal services
- 📞 Contact municipal departments
- 🔐 Secure user authentication
- 📱 Mobile-friendly, responsive design
- 🔐 Optional admin interface to view submissions

---

## 🚀 Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Supabase (Auth, Database, RLS)
- **Hosting:** [netlify](https://www.netlify.com)
